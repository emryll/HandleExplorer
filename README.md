# HandleExplorer
Interactive command-line tool for capturing, searching and analyzing handle data.

## Features
- Search for handles by describing object access
- Search for handles by describing a process or a list of pids
- Search for specific kinds of access by specific process
- Perform statistical analysis on the data in real-time
- Capture and export handle data
- Analyze previously captured data

## Usage
```
go build
./HandleExplorer.exe
```
*Run the help command if needed*
